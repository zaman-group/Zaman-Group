## Publish on GitHub Pages
1. Create a GitHub repository, for example `zaman-contracting-landscaping`.
2. Upload all files and folders from this package.
3. In GitHub, open **Settings → Pages**.
4. Select the branch containing `index.html` and publish from the repository root.
5. GitHub Pages will provide a `github.io` website address.

GitHub Pages supports static HTML/CSS/JavaScript websites directly from a repository.

## Custom domain
If you later purchase a domain such as `zamancontracting.com`, add it under **Settings → Pages → Custom domain**, then configure the DNS records at your domain provider. GitHub recommends configuring the custom domain in Pages before changing DNS records.
